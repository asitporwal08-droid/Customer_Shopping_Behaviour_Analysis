# Customer Shopping Behaviour Analysis

## Project Overview
This project analyzes customer shopping behaviour to identify purchasing trends, popular product categories, payment preferences, and customer demographics.

## Tools Used
- Python — Data cleaning and analysis
- SQL — Data querying and analysis
- Power BI — Interactive dashboard and visualization
- Excel/CSV — Dataset handling

## Key Insights
- Clothing is the leading purchase category.
- PayPal is the most frequently used payment method in the current analysis.
- Spring has the highest purchase count among the four seasons.
- Male customers represent approximately 68% of the dataset.
- Average purchase amount is approximately $59.76.

## Dashboard KPIs
- Unique Customers: 3,900
- Average Purchase Amount: $59.76
- Total Purchase Amount: $233,081

## Project Files
- `analysis.py` — Python analysis
- `customer_shopping_analysis.sql` — SQL queries
- `customer_shopping_cleaned.csv` — Cleaned dataset
- `Customer_Shopping_Behaviour_Analysis.pbix` — Power BI dashboard
- `Customer_Shopping_Behaviour_Dashboard.png` — Dashboard screenshot

## Objective
To turn customer shopping data into actionable insights that support business decisions.
